# PA指示書メーカー

セトリを選ぶだけで、PAへの曲ごとの指示（尺・音源・出し方・終わり方・備考）が入ったA4の指示書を作り、そのまま印刷できるツールです。

## 使い方
1. 「曲の登録」で曲と指示を一度だけ登録
2. 「セトリを組む」で曲を押した順に並べる（↑↓で入れ替え、MCも挿入可）
3. 「印刷する」→ 用紙A4・ヘッダーとフッターはオフで印刷

「CDを作る」タブでは、セトリ順に音源を番号付きでコピーしたCD用フォルダを作れます（PCのChrome/Edge）。あとはWindows Media Player／ミュージックアプリで音楽CDとして書き込むだけです。

曲リストは「曲の登録」からCSVで書き出し・読み込みができます（Excelで編集可）。

データはそのPCのブラウザに保存されます。PCを替えるときは「控えをファイルに書き出す」で移せます。

説明書：https://travis555jp.github.io/setlist/manual.html
